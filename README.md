# Hi there, I'm Şevvalnur Altınok 👋

### 💻 Computer Engineering Student & Bioinformatics Researcher

I'm a 3rd-year Computer Engineering student with a strong passion for Bioinformatics, Computer-Aided Drug Design (CADD), Structural Biology and Molecular Docking. Leveraging my background in software development and scientific computing, I have previously built end-to-end analysis modules for protein data. My work includes implementing physicochemical profiling (molecular weight, pI, instability index), Kyte-Doolittle hydropathy plots, and Chou-Fasman secondary structure predictions. Additionally, I have developed regex-based motif scanning for PROSITE patterns, integrated the NCBI BLAST API for online homology analysis, and built interactive Matplotlib/Plotly visualization and automated PDF reporting pipelines.
